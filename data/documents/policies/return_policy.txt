
RETURN AND REFUND POLICY

1. Return Eligibility

Customers can request a return if the received product is
damaged, defective, or different from the ordered product.

2. Return Period

Customers should submit a return request within 7 days
after receiving the product.

3. Refund Process

After the returned product is inspected and approved,
the refund will be processed through the original payment method.

4. Damaged Products

Customers should provide order information and photos
of the damaged product when submitting a return request.

5. Order Verification

The support system must verify the customer's order
before providing order-specific refund assistance.
